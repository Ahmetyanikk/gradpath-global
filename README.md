# GradPath Global

Uluslararası yüksek lisans adayları için ülke, şehir ve üniversite karşılaştırma platformu.

## Özellikler

- Ülke ve üniversite programlarını karşılaştırma
- Öğrenciyken çalışma izinleri
- Mezuniyet sonrası çalışma izinleri
- GPA beklentileri
- Yaşam maliyeti ve şehir büyüklüğü
- Teknoloji iş piyasası görünümü

## Geliştirme

```bash
npm install
npm run dev
```
